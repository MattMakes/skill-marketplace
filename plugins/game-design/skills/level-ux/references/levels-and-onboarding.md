# Levels and onboarding

Sources:
- Stone Librande, "One-Page Designs", GDC 2010: the level "musical score" (the Diablo act map
  lists every waypoint, enemy type and expected player level along the route) and the time plus
  space map.
- Jesse Schell, *The Art of Game Design: A Book of Lenses*: the Lens of the Interest Curve and
  the lenses on interface (feedback, the player's mental model).
- Tracy Fullerton, *Game Design Workshop*: formal elements (player actions, procedures, rules)
  and designing for the player's experience.

## The first 10 minutes

The first minutes decide whether the player stays. Put the core verb in the player's hands in
the first seconds. Teach each rule by letting the player do it once in a safe place, then use it.
Write down what the player learns at each beat: if a beat teaches nothing and delivers no target
kind of fun, cut it.

## Three sample levels

Three levels show the range of the design:
- **Early**: one element, low difficulty, the primary kind at its clearest.
- **Middle**: two elements combine; the player makes a real choice.
- **Late**: the hardest mix; the peak of the interest curve.

Like Librande's level score, give each level a goal, the new element, a difficulty number and
the kind of fun it serves, so the whole run reads as a rising line.

## Controls and HUD

Map every action to each control scheme you support. One action per input where you can. The HUD
shows only what the player needs for the next decision. Everything else goes to a menu or out.

## Screen flow

Draw every screen and every way between them: title, play, pause, settings, end. A screen with no
way out, or a setting reachable only from the title, is a bug in the flow.
