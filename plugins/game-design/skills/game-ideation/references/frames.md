# Ideation frames

A frame is a lens for turning a constraint card into a concept. Write each concept through a
**different** frame, so the six concepts differ in kind, not only in detail. Use the frame name
exactly as written here in the `frame` field.

| # | Frame | Ask this | Example move |
|---|---|---|---|
| 1 | **Toy first** | What is fun to poke at for 30 seconds, with no goal at all? Build the game around that toy. | A fog you can push with a fan becomes a lighthouse puzzle. |
| 2 | **Verb stretch** | Take the core verb to its extreme: 1000 times, at huge scale, or in slow motion. | "Tend" one plant → tend a whole forest from orbit. |
| 3 | **Inversion** | Play the other side: the system, the obstacle, the helper, the place. | Play the fog, not the keeper. |
| 4 | **Genre graft** | Put the card inside an existing genre that seems wrong for it. | A lighthouse game as a rhythm game. |
| 5 | **Real-world system** | Model a real job, craft or natural system faithfully, then make it playful. | How real lighthouse keepers logged weather and ships. |
| 6 | **Feeling first** | Start from one target-fun moment and design the 10 seconds around it. | The moment a lost ship's lights appear through the fog. |
| 7 | **Board-game translation** | Design it as a tabletop game with cards, tiles and dice; then ask what a computer adds. | Fog tiles flip each round; the computer hides the draw pile. |
| 8 | **Child's rules** | How would a ten-year-old play this on a playground? Keep their rules. | "Whoever the light touches has to freeze." |
| 9 | **One-screen** | The whole game fits on one static screen with no scrolling. What is the depth? | One lighthouse room, many dials. |
| 10 | **Constraint amplify** | Take the twist and make it the entire game, not a feature. | The fog remembering is the only mechanic. |

## Rules

- Six concepts need six different frames. Never reuse a frame in one run.
- A caller-supplied concept uses the frame `supplied`.
- Name the frame, then write the concept. Do not explain the frame in the output.
