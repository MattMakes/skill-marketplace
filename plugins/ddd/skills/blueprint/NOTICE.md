# Notice of origin

`blueprint` is a renamed copy of **archify 2.17.0-dev.1** by tt-a1i (MIT, https://github.com/tt-a1i/archify), itself based on Cocoon-AI/architecture-diagram-generator (MIT). The MIT text in `LICENSE` is archify's, unchanged. Removed from the copy: the update checker (`scripts/check-update.mjs`, `scripts/update-contract.mjs`, `skill-release.json`) and the "Update awareness" section of SKILL.md; the test suite (`test/`); the dev-only generators (`scripts/generate-brand-marks.mjs`, `scripts/generate-validators.mjs`) and the devDependencies they needed (ajv, parse5, saxes, simple-icons), so the package has no dependencies at all; `package-lock.json`; and upstream's `THIRD_PARTY_NOTICES.md`, whose brand-mark provenance table (Simple Icons CC0 plus the individually licensed Angular, Airflow, Kafka, .NET, JavaScript, Jenkins, Rust, Vue and OpenAI marks) belongs in the plugin's `shared/THIRD_PARTY_NOTICES.md` because `renderers/shared/generated-brand-marks.mjs` and `brand-marks/catalog.json` are vendored here. Renamed: `bin/archify.mjs` is `bin/blueprint.mjs`; the CLI name, the `ARCHIFY_*` environment variables (now `BLUEPRINT_*`, no aliases), the `window.Archify` viewer runtime, the `<!-- ARCHIFY:* -->` template sentinels, element ids and CSS class names, the product name in generated HTML, doctor output and diagnostics, and the schema `$id`s all say blueprint. The visual preset named `blueprint` that archify already shipped (`meta.visual_preset: "blueprint"`) is unchanged; it is a style name, not this skill. Files whose header named the product carry a `// blueprint: renamed copy of archify <path> (MIT, tt-a1i)` line.
