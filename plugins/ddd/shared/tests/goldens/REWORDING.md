# Rewording of Python-era messages (leaf 1.4.1)

The goldens under this directory were recorded from the Python scripts before those scripts
were deleted (see `../README.md`). Their stdout, stderr and written files quoted hints that
named Python scripts (`run prefill.py --write first`, `bump produced_at with stamp.py`, the
`render_chart:` stderr prefix, the `generated by ddd-define/scripts/render.py` marker). The
Node ports printed those strings verbatim through phase 1.3 so parity stayed provable; leaf
1.4.1 then reworded the Node messages to the `ddd <cmd>` form and applied exactly the same
substitutions to the recorded snapshots, so a replay still compares byte for byte.

`reword.mjs` reads the table below and applies it, in order, to every `stdout.txt`,
`stderr.txt` and `files.json` under `goldens/` (`meta.json` is never touched: it records the
Python twin that was run). Rows are plain substrings, applied top to bottom; the specific
phrases come first so an ambiguous script name such as `prefill.py` (define or code) is
resolved by its sentence before any generic row runs. Every replacement is ASCII with no
quote or backslash, so the same row is valid inside a JSON string in `files.json`.

```bash
node plugins/ddd/shared/tests/goldens/reword.mjs            # apply to the goldens (idempotent)
node plugins/ddd/shared/tests/goldens/reword.mjs --check    # exit 1 if any old phrase is still there
node plugins/ddd/shared/tests/goldens/reword.mjs --check <file-or-dir> ...   # scan other text
```

## Review goldens re-baselined from Node (not a substitution)

The six `review` variants (`default` and `out-title` on each fixture) were recorded from
`review.py`, whose page the plan handed to leaf 1.2.4 for a redesign; `golden.mjs` already
treated review as its one policy exception (`files: "paths"`, the `(NN KB)` figure masked).
After 1.2.4 the Node page prints a different worklist (open decisions lead it) and the example
workspace ships a `review.html`, so those snapshots could never match again and `review.py`
no longer exists to re-record them. Leaf 1.4.1 re-recorded the six from the Node CLI with
`--no-diagrams` added to both variants so the snapshot does not depend on whether a Chrome is
installed; their `meta.json` names the Node CLI as the twin. Every other golden is still the
Python recording plus the table above.
