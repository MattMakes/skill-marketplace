## B. `ddd/03-decompose/decompose.json` skeleton (types matter)

```json
{
  "schema_version": 1,
  "step": "decompose",
  "produced_by": "ddd-decompose",
  "produced_at": "<UTC now, must be later than discover.json produced_at>",
  "mode": "auto",
  "depth": "light",
  "inputs": ["ddd/02-discover/discover.json", "ddd/01-understand/understand.json", "ddd/glossary.md", "ddd/manifest.json"],
  "assumptions": [ { "id": "A1", "text": "…", "confidence": "low|medium|high" } ],
  "open_questions": [ { "id": "Q1", "text": "…", "blocking": false, "owner": "domain expert" } ],
  "notes_for_downstream": [ { "id": "N1", "text": "…", "for": ["define"], "kind": "language" } ],
  "subdomains": [
    { "id": "ordering", "name": "Ordering", "description": "…",
      "capabilities": ["cap-order-management"],
      "events": ["order-placed"], "commands": ["place-order"],
      "terms": ["Order"],
      "heuristics_applied": ["language-boundary", "pivotal-event"],
      "rationale": "…" }
  ],
  "bounded_contexts": [
    { "id": "ordering", "name": "Ordering", "subdomains": ["ordering"],
      "owns_events": ["order-placed"], "owns_commands": ["place-order"], "owns_aggregates": ["order"],
      "terms": [ { "term": "Customer", "meaning_here": "the party placing the order" } ],
      "wraps": [],
      "independent_service_check": { "sense_check": "yes", "brand": "yes", "revenue": "partial", "cost_tracking": "yes",
                                     "data": "yes", "user_personas": "yes", "cognitive_load": "yes", "verdict": "candidate" },
      "rationale": "…" }
  ],
  "relationships": [
    { "id": "R1", "upstream": "catalog", "downstream": "ordering", "pattern": "customer-supplier", "description": "…" }
  ],
  "context_map_mermaid": "flowchart LR\n  catalog[\"Catalog\"]\n  ordering[\"Ordering\"]\n  catalog -->|\"R1 customer-supplier\"| ordering",
  "deprecated": [ { "id": "Q2", "collection": "open_questions", "reason": "answered: …", "since": "2026-08-29" } ]
}
```

Type reminders that bite: `subdomains[].terms` is a list of **strings**; `bounded_contexts[].terms` is a
list of **objects** `{term, meaning_here}`; `open_questions[].blocking` is a boolean; `heuristics_applied`
values come from the slug list in SKILL.md (the check script warns on others); `bounded_contexts[].wraps`
is optional and additive (external system ids this context stands for); `notes_for_downstream[].for` holds
bare later step names; `deprecated[]` items are `{id, collection, reason, since}` where `collection` is the
list the item left (`open_questions`, `assumptions`, `relationships`, `bounded_contexts`, …) — re-runs
only, contract §7; `produced_at` is set by `ddd decompose check --stamp`, not by hand.
