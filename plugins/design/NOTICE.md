## Changes made here

Every skill keeps its upstream `name:` as the directory name. Beyond frontmatter, these were changed:

- `a11y-audit` — script paths rewritten to `${CLAUDE_PLUGIN_ROOT}/skills/a11y-audit/scripts/...`; the usage docs in SKILL.md and three references were corrected to the options the shipped scripts actually accept (the upstream text described `--fg/--bg`, `--file`, `--format table`, `--baseline`, `--report`, `--quiet` and `--ci`, none of which exist; the scanner's JSON key is `findings`); the related-skills table of non-vendored agents replaced with one sentence pointing at `design:` siblings; `expected_outputs/` and the sample component dropped.
- `accessibility`, `core-web-vitals`, `web-quality-audit` — `../` links between siblings rewritten as `design:` references; links to the non-vendored `performance`, `seo` and `best-practices` siblings dropped. `web-quality-audit`'s SKILL.md now mentions its bundled `analyze.sh`, and the script was fixed so directory scans report results (results were lost in a pipe subshell) and the `alt` check runs (it used a PCRE lookahead under `grep -E`).
- `design-is` — `/make-plan` repointed at `dev:create-plan`, `/do` at `dev:execute-plan`, `/review` at an ordinary code review; the `agent-browser` skill replaced with "a browser tool"; subagents named as the Agent tool.
- `design-md` — `visual-design/frontend-design`, `visual-design/impeccable/commands/extract` and `marketing/brand-identity` repointed at `design:frontend-design`, `design:impeccable` (`extract`) and plain prose; `popular-web-designs` and `claude-design` references dropped; `write_file` became the Write tool. Same in `references/source-modes.md`.
- `design-review` — the Surge deploy made optional (hand over the local HTML report; deploy only if the user wants a hosted link). Same in `references/in-context-preview.md`.
- `frontend-slides` — `source ~/.hermes/.env` removed; the Gemini SVG helper now runs only when `GEMINI_API_KEY` is already set; a Hermes Signal-gateway `MEDIA:` line and the `browser_vision` tool name removed; Surge deploys marked optional; `references/related-skills.md` repointed at `design:frontend-design` and `design:impeccable`.
- `emil-design-eng`, `review-animations`, `web-design-guidelines` — Open Design's `triggers:` and `od:` frontmatter blocks removed; the upstream project and source commit kept under `metadata:`; descriptions rewritten as single lines with "Use when" triggers; `argument-hint` lifted to a top-level key.
- `hallmark` — `open-design.json` sidecar dropped; the `<question-form>` protocol replaced with the AskUserQuestion tool; links to the upstream repo's `site/css/tokens.css`, `docs/recipes.md`, `docs/study-examples.md` and `site/_tests/` (not part of the skill) turned into GitHub links or plain text; three dangling links inside `references/components/` fixed.
- `impeccable` — every `.claude/skills/impeccable/scripts/impeccable` invocation rewritten to `${CLAUDE_PLUGIN_ROOT}/skills/impeccable/scripts/impeccable`; Setup step 1 now says where the engine binary comes from and that the playbooks work without it. Scripts, engine data and the Windows `.cmd` launcher kept as shipped.
- `ui-ux-pro-max` — `${CLAUDE_PLUGIN_ROOT}/.claude/skills/ui-ux-pro-max/scripts/search.py` rewritten to `${CLAUDE_PLUGIN_ROOT}/skills/ui-ux-pro-max/scripts/search.py` (11 places); `data/phosphor-icons-upstream.json`, `data/google-font-licenses.json`, `data/catalog-summary.json`, `data/data-provenance.json`, `scripts/tests/` and `scripts/validate_data.py` dropped (nothing the search reads); `data/google-fonts.csv` trimmed from 1,934 rows to the 150 most popular plus 30 trending families (361 rows).
- `frontend-design`, `make-interfaces-feel-better`, `design-system-patterns`, `screen-reader-testing` — unchanged apart from the name check.
