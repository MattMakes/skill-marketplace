## Changes made here

Every skill keeps its upstream method and wording. Beyond setting `name:` to the directory name,
these copies differ from upstream as follows:

- `validate-data`, `explore-data`, `build-dashboard`, `metrics-review`, `roadmap-update`,
  `stakeholder-update`, `competitive-brief`, `review-contract`, `triage-nda`, `ticket-triage`,
  `customer-escalation`: removed the pointer to the plugin-level `CONNECTORS.md`; rewrote each
  `~~connector` placeholder as "if an MCP connector for X is available"; namespaced the skill's own
  slash command to `/work:<skill>`. `ticket-triage`'s `/customer-escalation` reference became
  `work:customer-escalation`. `build-dashboard`'s "if data warehouse is connected" uses the same
  MCP-connector phrasing. `review-contract` and `triage-nda` no longer tell the model to look for
  `legal.local.md` "in local settings"; the playbook is now a document the user points to or a
  similarly named file in the working or home directory, with the same fallback to generic
  standards.
- `sql-queries`, `data-visualization`, `variance-analysis`, `file-conversion`: unchanged.
- `statistical-analyst`: script invocations use `${CLAUDE_PLUGIN_ROOT}/skills/statistical-analyst/scripts/`;
  the "Related Skills" table naming sibling skills from the upstream repository was dropped and
  its "when not to use" bullets became a short Scope paragraph.
- `statistical-analysis` folded into `statistical-analyst` on 2026-11-05. Its descriptive
  statistics, trend and forecasting, outlier detection and cautions sections became
  `references/descriptive-trend-and-outliers.md` (wording unchanged; a new intro) and a new
  Mode 4 in SKILL.md; the "Entry Points" heading became "Modes"; paired t-test and ANOVA joined
  the test selection table; correlation-as-causation and survivorship bias joined the risk
  triggers. Dropped as duplicates of `statistical-analyst`: its hypothesis-testing basics
  (framework, test table, practical vs statistical significance, sample size rule of thumb) and
  its multiple-comparisons and Simpson's Paradox notes; also its `user-invocable: false` flag.
- `writing-clearly-and-concisely`: deleted the README.md that repeated SKILL.md (its attribution
  is recorded in the table above); "dispatch a subagent" names the Task/Agent tool; the reference
  table's file names carry their `elements-of-style/` directory.
- `crafting-effective-readmes`: deleted the README.md that repeated SKILL.md; the reference to
  `writing-clearly-and-concisely` in `style-guide.md` became `work:writing-clearly-and-concisely`.
  In the vendored references, the translations line at the top of `art-of-readme.md` (links to
  upstream `README-<lang>.md` files) was removed and the spec's `README.md#background` link now
  points at the standard-readme repository; in `templates/oss.md` and
  `standard-readme-example-maximal.md` the `[…](CONTRIBUTING.md)` links became `CONTRIBUTING.md`
  in code spans so the template does not carry a link to a file that is not there.
- `writing-guidelines`: frontmatter rebuilt: single-line description, `argument-hint` promoted
  from metadata, the `triggers` and `od` host keys dropped, upstream URL and source commit kept
  under `metadata`. Body unchanged.
- `to-questionnaire`: deleted `agents/openai.yaml`; the description gained a "Use when" clause.
- `grounded-vault`: `scripts/check_vault.py` was written out verbatim from the code block in
  `references/details.md` (upstream ships the script only inline); SKILL.md says where it lives.
  The sentence pointing at the upstream repository's context-management and conductor plugins
  became plain prose.
- `market-sizing-analysis`, `startup-metrics-framework`: the `version` key moved under `metadata`.
- `video-editor`: the `{baseDir}` example path is now `${CLAUDE_PLUGIN_ROOT}/skills/video-editor`
  instead of the author's `~/clawd/skills/video-editor`; the author's "Bloom" app in one recipe
  was generalised to a placeholder. `scripts/edit.sh` is unchanged.
- `frontend-slides` — `source ~/.hermes/.env` removed; the Gemini SVG helper now runs only when `GEMINI_API_KEY` is already set; a Hermes Signal-gateway `MEDIA:` line and the `browser_vision` tool name removed; Surge deploys marked optional; `references/related-skills.md` repointed at `design:frontend-design` and `design:impeccable`.
  Moved here from the `design` plugin in the v3 taxonomy (2026-11-05).
- `technical-writing`: `disable-model-invocation: true` removed from the frontmatter (upstream set
  it for Cursor's `poteto-mode` router, which was not vendored); `unslop` references became
  `work:humanize`. Moved here from the `pstack` plugin in the v3 taxonomy (2026-11-05).
- `humanize`, `mochi-deck`: moved here from the dissolved `tools` plugin in the v3 taxonomy
  (2026-11-05), unchanged apart from cross-references. The credits above were carried from the
  `tools` README.
